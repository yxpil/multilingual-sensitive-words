# Multilingual Sensitive-Words List（多语言敏感词库）

内容审核用的**多语言敏感词库**，覆盖 108 种语言，专为「AI 审核不可用时的关键词降级/过滤」设计。

> 原词库来自 [BUI](https://yxpil.com) 博客项目的 `moderate.ts` 审核降级逻辑：AI 判 `pending`（不可用/判不出）时，命中词库 → `rejected`（拦截），否则 → `approved`（放行）。

## 为什么做多语言版本

站点支持多语言界面后，用中文词库无法过滤其他语言的违规内容。本仓库把 5 类中文敏感词机翻成各语言版本，供不同语言用户的评论/私信/书曲做关键词降级审核。

## 原始词库来源

本仓库的中文原版词库（`data/sensitive-words/` 下 5 个文件）源自开源项目 [fwwdn/sensitive-stop-words](https://github.com/fwwdn/sensitive-stop-words) 的敏感词清单（色情类 / 政治类 / 广告 / 涉枪涉爆违法信息 / 网址），按原始格式整理后作为本仓库多语言机翻的基础。多语言版本均为基于该原始中文词库的机翻，版权归原项目所有。

## 词库分类

| 文件（中文原版） | 内容 | 分隔 |
| --- | --- | --- |
| `sw_色情类.txt` | 色情/低俗词 | 逗号 |
| `sw_政治类.txt` | 政治敏感词 | 逗号 |
| `sw_广告.txt` | 广告/营销词 | 每行一词 |
| `sw_涉枪涉爆违法信息关键词.txt` | 涉枪/涉爆/违法词 | 每行一词 |
| `sw_网址.txt` | 网址/推广链接特征 | 每行一词 |

## 目录结构

```
data/
  sensitive-words/          # 中文原版（逗号/行分隔）
  i18n/
    <lang>/                 # 每种语言一套翻译
      sw_色情类.json
      sw_政治类.json
      sw_广告.json
      sw_涉枪涉爆违法信息关键词.json
      sw_网址.json
languages.txt               # 覆盖语言代码清单
```

## 翻译方式

- 用**专用机翻引擎**（`translators` 库 / Bing 机翻接口），**非通用大模型**。
- 翻译质量为机器水平，用于**过滤/初审**，可能含误译、漏译，建议上线前人工抽检。

## 使用

把对应语言词库按你的审核引擎加载：命中任一词 → 拦截。参考原版 `moderate.ts` 的关键词降级逻辑：

```
命中任一敏感词 → rejected（违规）
否则           → approved（放行）
词库缺失       → pending（交人工/不拦截）
```
